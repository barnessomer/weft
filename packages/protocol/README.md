# @weft/protocol

Weft Coordination Protocol (WCP) v0.1 — the wire contract between agent adapters, the
per-repo coordinator, observers (Hérmes iOS, web) and human actions.

Spec (normative): [`docs/protocol/wcp-v0.md`](../../docs/protocol/wcp-v0.md).

## Contents

| Export | What |
|---|---|
| `types.ts` | TypeScript types for every message, event, diagnostic |
| `schema` / `schema/wcp-v0.schema.json` | JSON Schema draft 2020-12 (`$defs/<Message>`), generated by `pnpm gen` |
| `validate(name, value)`, `assertValid`, `validateMessage(msg)` | Workers-safe validators (schema interpreter, no `eval`); issues are JSON Pointer paths |
| `ReferenceCoordinator` | in-memory, deterministic implementation of §5–§9 (validation rules, arbitration, claims, inbox, gates, human actions, paging) |
| `runScenario`, `ConformanceTarget`, `scenarioClock`, `partialMatch` | conformance runner for `fixtures/scenarios/*.json` |
| `summarize` | reference one-line human summary (§6.4) |
| `renderContext`, `renderDiagnostic` | the model-visible squiggle text adapters inject (§8.3) |
| `encodeCursor`, `decodeCursor`, `mergeFeed` | combined-feed cursor and merge (§9.5) |
| `WcpProtocolError`, `ERROR_STATUS`, `closeCode` | error codes → HTTP / WS close codes (§11) |

## Fixtures

- `fixtures/messages/valid/*.json`, `fixtures/messages/invalid/*.json` — `{schema, value[, expect_issue_path]}`; regenerate with `python3 scripts/gen-message-fixtures.py`.
- `fixtures/scenarios/*.json` — behavioural scenarios with hand-derived expectations; regenerate with `python3 scripts/gen-scenarios.py`.

The test suite checks every fixture with both this package's validator and Ajv (strict),
runs every scenario against `ReferenceCoordinator`, validates every response it emits,
and checks deterministic replay.

## Running the scenarios against another coordinator

```ts
import { runScenario, scenarioClock, type ConformanceTarget, type Scenario } from "@weft/protocol";

const clock = scenarioClock(scenario.start);
const target: ConformanceTarget = makeTargetForMyCoordinator(clock.now); // hello/submit/drain/…/tick
const results = await runScenario(scenario, target, clock);
expect(results.filter((r) => !r.ok)).toEqual([]);
```

The coordinator under test must take its clock from `clock.now` (claims/sessions expire
on `tick`) and use the scenario's `policy`, `claim_ttl_ms` and `session_ttl_ms`.

# Roadmap

Public 12-month roadmap. Progress is tracked in issues and in the AAIF proposal
([aaif/project-proposals#53](https://github.com/aaif/project-proposals/issues/53)).

## Q4 2026

- Tag **Agent Hooks Core v0.1** and **WCP v0** as the first spec releases.
- Short heartbeat-renewed claim leases and hard limits on firm claims (per-repo policy recorded
  in the journal).
- GOVERNANCE.md, MAINTAINERS.md, SECURITY.md (done); OpenSSF Best Practices badge.
- Engage the AAIF Workflows & Process Integration and Security & Privacy working groups.

## Q1 2027

- A second, independent implementation of the Hooks Core (a coordinator not built on Cloudflare).
- The first outside organization running Weft in production.
- A second maintainer from another organization.
- Hook adapters accepted upstream by at least one agent harness.

## Q2–Q3 2027

- Hooks Core v1.0 release candidate, with conformance tests run by several hosts.
- WCP v1: multi-repository coordination and observer roles.

## How to help

Implement the Hooks Core in another runtime, run Weft with your agents and report what breaks, or
pick an issue. See [CONTRIBUTING.md](CONTRIBUTING.md).
